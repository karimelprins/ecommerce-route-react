# Project Plan

## Goal

Build a polished React e-commerce application that demonstrates practical frontend skills including REST API integration, authentication, protected routes, reusable components, cart/wishlist flows, checkout, validation, and responsive UX.

## Core Pages

- Home
- Products
- Product Details
- Categories
- Brands
- Login / Register
- Cart
- Wishlist
- Checkout
- Order Success

## Quality Checklist

- Toast notifications instead of blocking alerts
- Skeleton/loading states
- Form validation
- Error and empty states
- Responsive layouts
- Production deployment
- Clear README and live demo

## Portfolio Summary

Built a React e-commerce application using the Route E-commerce API with product browsing, filtering, product details, authentication, protected routes, cart, wishlist, and checkout flows.
